# F1 Manager Database Editor - 中文汉化版

> 基于 [IUrreta/DatabaseEditor](https://github.com/IUrreta/DatabaseEditor) 的中文汉化版本

## 📖 项目介绍

F1 Manager 2023/2024 存档数据编辑器的中文汉化版本，支持完整的游戏存档编辑功能。

### 主要功能
- ✅ 车手/工作人员管理（转会、合同、属性编辑）
- ✅ 车队管理（设施、预算、目标）
- ✅ 赛车性能编辑
- ✅ 赛历自定义
- ✅ 2025赛季模组支持
- ✅ 2026赛季模组支持（已关闭）
- ✅ 完整中文界面
